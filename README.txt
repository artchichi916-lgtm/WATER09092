污水處理與管網維護／減量與防治 測驗網站 v1.0
====================================================

一、題庫
- 原始檔：減量、防治.md
- 第一部分：管網維護與操作診斷 155 題
- 第二部分：防治、減量與再生水 142 題
- 合計：297 題
- 網站解析結果：297 題皆為四選一，無漏題。

二、每回測驗規則
- 每回最多 40 題。
- 題庫分為 8 大主題，一般情況每類抽 5 題，共 40 題。
- 若接近題庫完成、某類剩餘題數不足 5 題，缺額由其他尚未掌握類別補足。
- 錯題與尚未答對題目共同進入候選池，錯題會優先複習。
- 答對題目立即列為「已掌握」，後續不再出題。
- 答錯或未作答題目列入「錯題」，之後仍會再出題；答對後即移出錯題池。

三、交卷後
- 百分制成績。
- 顯示答對／答錯題數。
- 依 8 大主題分析本回正確率及累計正確率。
- 提供弱項與加強方向。
- 顯示全部本回題目、你的答案與正確答案。
- 答對題綠色、答錯題紅色。

四、學習紀錄
- 使用瀏覽器 localStorage 儲存，不需要伺服器或資料庫。
- 同一瀏覽器重新開啟網站仍會保留已掌握與錯題。
- 換電腦／瀏覽器、無痕模式或清除瀏覽資料，紀錄不會自動同步。
- 網站提供「匯出紀錄／匯入紀錄」功能供備份。

五、GitHub Pages 發布
1. 建立新的 GitHub repository。
2. 將 ZIP 解壓縮後的所有檔案直接上傳至 repository 根目錄。
3. GitHub repository → Settings → Pages。
4. Source 選 Deploy from a branch。
5. Branch 選 main，資料夾選 /(root)，按 Save。
6. 等 GitHub 顯示公開網址後即可分享。

六、主要檔案
- index.html：網站入口
- style.css：版面樣式
- app.js：抽題、判分、錯題、弱項分析與學習紀錄
- questions.js：297 題網站題庫
- 減量、防治_原始題庫.md：原始題庫備份
- 題庫分類統計.json：網站分類結果
